# HIGGS Dataset – Big Data Classification Project

This repository contains a complete big data analytics pipeline for binary classification of particle collision events using the HIGGS dataset.

## Project Overview
The project leverages Apache Spark for distributed data processing and machine learning, and Tableau for interactive visualization and decision support.

## Key Components
- Spark-based preprocessing and ML pipelines
- Distributed model evaluation and scalability analysis
- Tableau dashboards for data quality, model performance, business insights, and cost analysis
- Reproducible environment and testing setup

## Repository Structure
- `run_pipeline.py` – Main Spark ML pipeline
- `performance_profiler.py` – Performance and scalability profiling
- `spark_config.yaml` – Spark configuration
- `tableau_config.json` – Tableau dashboard configuration
- `tests/` – Unit tests
- `README_tableau.md` – Tableau dashboard documentation

## How to Run
Use `environment.yml` for Conda setup or the provided `Dockerfile` for containerized execution.
